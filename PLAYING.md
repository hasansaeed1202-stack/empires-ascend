# Playing the one-map demo

Open this project in Godot 4.7.2 and run the project (`F6`/`F5`).

- Move the camera with WASD or arrow keys; zoom with the mouse wheel.
- Left-click a unit to select it. Right-click terrain to move; right-click an enemy to attack.
- Use the HUD buttons, then left-click open terrain, to build a house, farm, resource camp, or barracks.
- Select villagers, then left-click a completed farm or resource camp to assign them. Farms gather Provisions; camps gather Materials.
- Build a barracks and use **Train Soldier**. Destroy the red enemy Town Center to win.
- **Restart** resets the match and **Exit** closes the game.

The demo intentionally uses lightweight engine primitives and caps total units at 24 for modest hardware. A Windows executable is optional; editor launch remains the supported fallback when matching export templates are unavailable.
